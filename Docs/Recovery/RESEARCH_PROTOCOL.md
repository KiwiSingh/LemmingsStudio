# Creator research protocol

Recruit 8–12 consenting adult creators, spread across beginner, intermediate and experienced production. Do not contact participants or collect recordings without authorization. Record consent and anonymize notes. Do not upload private music to model providers without participant permission.

Ask each participant to install from a fresh environment, create/import an eight-bar arrangement, edit MIDI, record audio, use an assistant edit, revise it, save/reopen and export stems. Let them explain expectations before showing the intended path. Capture completion, time, errors, workarounds, confidence and recovery ability. Avoid leading questions about competitor features.

Template for each task: participant code, experience, OS/interface, task, expected result, observed steps, completion, minutes, blocking error, recovery, quote with consent, severity and proposed response.

Priority rubric: data loss first, then inability to install/record/open/export, then repeated workflow friction, then discoverability and sound breadth. Separate observed failures from suggestions and researcher interpretation.

The implementation agent has not conducted these interviews. A human recruiting/consent step and actual participants are required; fabricated results are prohibited.
