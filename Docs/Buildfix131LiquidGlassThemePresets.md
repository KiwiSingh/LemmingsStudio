# Buildfix 131 — Liquid Glass Theme Presets

Adds selectable Liquid Glass theme presets and original themed glyph systems.

## Added themes

- Liquid Glass — the buildfix130 default.
- World Cup 2026 — pitch green, stadium glow, trophy gold, football glyphs.
- Cyberpunk 2077-ish — neon yellow/cyan/magenta dystopian glass.
- Hot Pink — glossy club-pink glass.
- Anime Racing — racing-idol/anime energy using ribbons, stars, flags, and speed glyphs.
- Elemental Fantasy — anime fantasy palette with teal, violet, gold, wind/flame/sparkle glyphs.
- Alien Club — Diplo/EDM alien-club vibe with original alien/antenna/cosmic glyph language.
- Spatial Future — Apple Vision Pro-like spatial glass: airy blue-white panels, soft chrome, deep blur.

## UI entry points

- Transport strip now has a compact theme menu.
- Settings → Appearance has the full theme picker and preview cards.

## Design rules

All themes keep the buildfix130 Liquid Glass rules:

- translucent material panels;
- rounded continuous geometry;
- subtle glass strokes;
- bloom/glow background gradients;
- readable foreground contrast;
- themed but original SF Symbol glyph systems.

No official logos, mascot art, album art, or game UI assets are used.
