# Open Sample Downloader

LemmingsStudio now includes an optional downloader for open sample libraries. It downloads archives into `User Library/Open Samples` instead of silently bundling third-party audio.

Included sources:

- VSCO 2 Community Edition: open orchestral library, CC0/public-domain style.
- VCSL: Versilian Community Sample Library, CC0 world/acoustic/percussion library.
- Open Samples: community open sample project; verify individual pack metadata before redistribution.
- Infinite State Open Source Sample Pack: synth/drum-loop pack; verify included license text before redistribution.
- Bhangra / Indian percussion: metadata-only until a verified CC0 Bhangra sample repository is added. Use Splice, owned packs, or VCSL world percussion in the meantime.

The downloader intentionally keeps licenses visible because beta DAW builds should not scrape and rebundle samples blindly.
