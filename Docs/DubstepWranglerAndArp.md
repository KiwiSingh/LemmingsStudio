# Dubstep Wrangler + Pattern Arp

Dubstep Wrangler is a dedicated bass/half-time generator device. It creates a step-sequencer track with a dubstep kit, wobble-sub lane, and Pattern Arp in the device chain.

Pattern Arp is a MIDI scheduling device. The audio engine reads its `octaves`, `rate`, `gate`, and `swing` parameters while scheduling MIDI/step hits. The current beta expands each note across octaves; deeper per-step timing can build on this without changing project files.

Oscillatron now adds an Exotic Lemmings Shape layer: a third, combined oscillator texture created from the three-oscillator blend rather than copying any vendor synth.
