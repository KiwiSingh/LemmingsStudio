# LemmingsStudio buildfix309 — visionOS release hardening

## Scope

buildfix309 is intentionally narrow. It preserves bf308 runtime behavior while hardening the user-facing packaging and Xcode development path.

## Changes

- Rebuilt the visionOS `AppIcon.imagestack` as a real three-layer icon:
  - Back: opaque purple-to-blue background plane.
  - Middle: waveform layer with transparency.
  - Front: mascot and foreground detail layer with transparency.
- Removed the two effectively blank icon layers from bf308.
- Kept `ASSETCATALOG_COMPILER_APPICON_NAME = AppIcon` as the target primary icon configuration.
- Added `Scripts/stage-xcode-models.sh` as an Xcode post-build phase generated by XcodeGen.
- Xcode `Command-R` builds now stage the selected MLX profile into the built app bundle before launch.
- Xcode model profile defaults to `minimal`; `full`, `default`, and `none` remain explicit overrides.
- Added `open-in-xcode.sh` to prepare the model cache, generate the Xcode project, and open it for interactive simulator testing.
- Preserved the existing unsigned/resignable IPA flow. End users still sign the IPA on their own Apple Developer account/provisioning workflow.
- No DAW runtime, audio, MIDI, automation, sample-browser, plugin-hosting, or spatial-keyboard behavior was intentionally changed in this buildfix.
